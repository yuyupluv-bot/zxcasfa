# V162 — без карточки ссылки в постах ротации

- Для сообщений, опубликованных системой ротации, передаётся параметр VK `dont_parse_links=1`.
- Ссылка остаётся в тексте и остаётся кликабельной, но VK больше не добавляет отдельное вложение-карточку «Ссылка».
- Настройка применяется только к постам ротации и не меняет остальные сообщения бота.
- Флаг сохраняется в transactional outbox, поэтому не теряется при отложенной отправке и повторных попытках.
- Добавлена линейная миграция `0051_outbox_dont_parse_links` и резервное автоматическое обновление схемы.
- Полный набор из 633 тестов проходит успешно.
