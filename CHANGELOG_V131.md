# V131 — позиция водителя после заявки

- Отмена активной заявки по причинам «Клиент не вышел» и «Клиент захотел отменить» возвращает водителя на первое место.
- Отмена активной заявки пассажиром возвращает водителя на первое место.
- Успешное завершение поездки или доставки отправляет водителя в конец очереди.
- Если есть параллельная заявка, она становится основной вместо возврата в свободную очередь.
- Миграция базы данных не требуется.
