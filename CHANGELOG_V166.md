# V166 — новое приложение водителя 1.7.0

- Полностью обновлён лёгкий интерфейс Android: главная, боковое меню и настройки.
- Добавлены светлая/тёмная темы и короткие анимации перехода без постоянной нагрузки.
- Водитель регулирует громкость сигнала, вибрацию и сценарии: обычная заявка, параллельная заявка, отмена.
- Приложение объясняет разрешения и открывает системные настройки уведомлений и ограничений батареи без запрещённого обхода Android.
- Удалено принудительное изменение системной громкости; используется выбранный локальный уровень.
- Добавлены HTTPS-only, защита резервных копий, WAKE_LOCK только на время сигнала и удаление push-токена при отключении устройства.
- Добавлен защищённый API `/api/driver-app/unregister`; существующие API бота и админки не изменены.
- Добавлены release signing, R8, Android Lint в GitHub Actions, политика конфиденциальности и чек-лист RuStore.
- Debug APK успешно собран, Android Lint пройден.
