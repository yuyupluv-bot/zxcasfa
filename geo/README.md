# Карта района и маршрутизация: опциональный изолированный сервис

Центр: 58.3747, 58.3213 (ориентир в Горнозаводске). Радиус выбора назначения
50 км по прямой, НЕ 50 км длины дороги. Граф дорог и тайлы готовятся по bbox
с запасом 70 км для объездов. Это ограничение навигатора, НЕ новый запрет
междугородних заявок в боте. Заявки и их таймеры не зависят от map-service.

Код не обращается к публичным OSM tiles/Nominatim/OSRM demo и не имеет
платных ключей. До подготовки файлов приложение честно показывает, что
карты района не установлены. Наличие исходников не равно готовой карте.

Нужны локальные файлы в geo/data:
- region.mbtiles: векторные тайлы OpenMapTiles-схемы, z0–14.
- region.osrm.*: подготовленный OSRM MLD граф с автомобильным профилем.
- addresses.sqlite: таблица addresses(label TEXT, normalized TEXT, latitude REAL,
  longitude REAL) с адресами/названиями, подтверждёнными в исходных данных OSM.
- fonts/Noto Sans Regular/<range>.pbf: разрешённые к распространению glyphs,
  включая кириллицу. Без них геометрия карты видна, но надписи не добавляются.

Источник — исходные данные OSM (например, Geofabrik), не скачивание тайлов
с tile.openstreetmap.org. Требуются атрибуция и соблюдение ODbL, лицензии
шрифтов и инструментов. Сохраните сведения о дате и источнике сборки.
Подготовку выполнять НЕ на рабочем сервере с ботом: она может требовать
существенно больше RAM, чем обслуживание готовых файлов.

Сервисы включаются отдельно профилем driver-maps после подготовки данных.
На reverse proxy нужно направить /driver-map/ и /api/driver-app/geo/ в
127.0.0.1:3100; остальные запросы оставляются на существующей админке/API.
Снаружи только HTTPS. DRIVER_GEO_PUBLIC_URL — публичный HTTPS origin.

Не запускать неограниченный PBF России на 4 ГБ RAM. Сначала измерить RAM,
время ответа OSRM и размер файлов на сборке района; контейнеры имеют лимиты,
а маршрутизатор не публикует свой порт во внешний интернет.


До установки профиля требуется отдельная проверка ресурсов сервера и загрузка настоящих наборов данных. Профиль не превращает пустой архив в готовый навигатор. Публичные OSM tile-серверы и OSRM demo не являются производственным запасным каналом.
