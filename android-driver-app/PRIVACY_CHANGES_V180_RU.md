# Проект изменений политики для V180 — согласовать до выпуска

Действующая `web/templates/privacy.html` описывает только приложение уведомлений и прямо говорит, что геолокация не запрашивается. Для нового приложения это уже неверно. **Не выпускать V180 и не публиковать прежнюю политику как описание GPS-приложения.**

Перед выпуском оператору необходимо согласовать и опубликовать новую редакцию:

- приложение читает рабочие заявки и отправляет подтверждённые водителем действия;
- точная геопозиция запрашивается отдельно для карты/построения маршрута; отказ не должен запрещать работу с заявками;
- в текущем тестовом коде GPS используется только при открытом экране; фонового доступа к геолокации нет;
- при запросе маршрута координаты начала/конца передаются по HTTPS собственному серверу сервиса и локальному OSRM; сторонний публичный маршрутизатор не используется;
- серверный код не создаёт отдельную историю траекторий водителя. Необходимо отдельно проверить конфигурацию прокси/журналов и фактические сроки хранения;
- технические квитанции мобильных действий очищаются после 7 суток; это не срок хранения исходных заказов, сообщений VK или резервных копий;
- FCM и правила удаления привязки остаются, но состав обрабатываемых данных и цели необходимо обновить.

Если будет добавлена фоновая навигация, текст и экран согласия пересматриваются ещё раз. Это технический список для согласования, не юридическое заключение.
