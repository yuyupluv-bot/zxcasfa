Приложение: «БЕЗТАКСЫ — водитель».

Оператор: самозанятая Перунова Анастасия Анатольевна.

Контакт по вопросам персональных данных: ilia.gat@yandex.ru.

Какие данные обрабатываются

Приложение обрабатывает только сведения, необходимые для подключения водителя и доставки рабочих уведомлений:

  • имя водителя, полученное при привязке приложения;
  • Firebase push-токен устройства;
  • внутренний идентификатор установки и случайный секрет установки;
  • технические данные уведомления: тип и номер заявки, маршрут и параметры сигнала.

Приложение не запрашивает геолокацию, контакты, SMS, журнал звонков, камеру, микрофон и доступ к пользовательским файлам.

Цели обработки

Данные используются только для привязки устройства к водителю, доставки уведомлений о новых и параллельных заявках и их отмене, а также для управления звуком и вибрацией. Данные не продаются, не используются для рекламы и профилирования.

Передача и инфраструктура

Уведомления доставляются через Firebase Cloud Messaging (Google). Сервер сервиса «БЕЗТАКСЫ» доступен на домене panel.bezrateadminps.ru. Передача данных между приложением и сервером выполняется по HTTPS.

Хранение и удаление

Push-токен и данные установки хранятся, пока устройство подключено. Водитель может удалить их через Настройки → Отключить устройство. После подтверждения запись установки и push-токен удаляются с сервера. Дополнительный запрос на удаление можно отправить на ilia.gat@yandex.ru.

Защита данных

Привязка выполняется ограниченным по времени кодом. Постоянный секрет установки передаётся по HTTPS и хранится на сервере только в виде криптографического SHA-256-хеша. Доступ к настройкам модерационного кода имеет только авторизованный администратор.
