# VK Taxi v111

## Вкладка «Водители»

- Статистика выполненных заявок расширена до последних 7 календарных дней.
- Для каждого водителя показано количество выполненных заявок за неделю и разбивка по дням.
- Водители в недельной таблице сортируются по количеству выполненных заявок.
- Добавлены общие показатели: выполнено за неделю, число работавших водителей и среднее число заявок на водителя.
- Внизу страницы добавлена таблица всех водителей с количеством отзывов и средней оценкой.
- Рейтинг сортируется по убыванию количества отзывов; при равенстве — по средней оценке.
- Водители без отзывов также отображаются в конце списка.
