# V164 — безопасное обновление и диагностика

- Миграции PostgreSQL защищены межпроцессной advisory-блокировкой: одновременный
  запуск bot, admin и migrate больше не может параллельно выполнять Alembic.
- Ошибки уведомлений о первом месте в очереди больше не подавляются молча и
  записываются в журнал без остановки основной очереди.
- Docker-образ помечен актуальной версией V164.
- Обновлена инструкция безопасного обновления через GitHub и Portainer:
  резервная копия, Pull Request, проверка GitHub Actions и ручной redeploy.
- Добавлены регрессионные проверки конфигурации выпуска.
