# БЕЗТАКСЫ 1.7.1 — сборка и установка приложения водителя

## 1. Что нужно заранее

- Android Studio с JDK 17;
- публичный HTTPS-домен админ-панели;
- Firebase-проект для package name `ru.taxi.driveralerts`;
- постоянный release keystore;
- опубликованная HTTPS-страница политики конфиденциальности.

## 2. Firebase

1. Создайте Android-приложение `ru.taxi.driveralerts` в Firebase.
2. Скачайте `google-services.json` в `android-driver-app/app/`.
3. Сервисный ключ Firebase храните на сервере как Portainer secret или в `FIREBASE_SERVICE_ACCOUNT_B64`.
4. Никогда не загружайте `google-services.json`, сервисный ключ или keystore в публичный GitHub.

## 3. Сервер

В Portainer должны быть настроены:

```env
FIREBASE_SERVICE_ACCOUNT_FILE=/app/secrets/firebase-service-account.json
VK_BOT_URL=https://vk.me/clubXXXXXXXX
PUSH_SOUND_DIR=/app/data/push_sounds
```

После обновления выполните **Pull and redeploy** с пересборкой. Миграция автоматически добавит поля для отзываемого модерационного кода RuStore.

## 4. Тестовая сборка

```bash
gradle :app:assembleDebug \
  -PDRIVER_APP_SERVER_URL=https://panel.bezrateadminps.ru \
  -PPRIVACY_POLICY_URL=https://panel.bezrateadminps.ru/privacy
```

Нельзя выпускать сборку со значением `CHANGE-ME`.

## 5. Release keystore

Создайте ключ один раз через Android Studio: **Build → Generate Signed Bundle/APK**. Храните несколько защищённых резервных копий. Без прежнего ключа Android не установит обновление поверх опубликованной версии.

Скопируйте:

```text
keystore.properties.example → keystore.properties
```

Заполните абсолютный путь к `.jks`, alias и пароли. Эти файлы уже исключены из Git.

## 6. AAB для RuStore

```bash
gradle :app:clean :app:bundleRelease \
  -PDRIVER_APP_SERVER_URL=https://panel.bezrateadminps.ru \
  -PPRIVACY_POLICY_URL=https://panel.bezrateadminps.ru/privacy
```

Файл: `app/build/outputs/bundle/release/app-release.aab`.

## 7. Доступ для модератора RuStore

1. После развёртывания откройте админ-панель.
2. Перейдите в **Приложение водителей**.
3. В блоке **Код для модератора RuStore** выберите отдельного тестового водителя.
4. Нажмите **Создать код на 30 дней** и сразу скопируйте показанный код.
5. Вставьте код в комментарий для модератора RuStore.

Код многоразовый, чтобы несколько проверок не требовали вашего участия. В базе хранится только его SHA-256-хеш. Код можно немедленно отозвать в том же разделе.

## 8. Настройка телефона водителя

При первом запуске приложение объясняет, зачем нужны уведомления и фоновая работа. Водитель должен:

1. разрешить уведомления;
2. открыть системные настройки батареи;
3. выбрать для БЕЗТАКСЫ режим «Без ограничений», если он доступен;
4. на Xiaomi/Redmi/Realme/Huawei дополнительно разрешить автозапуск в системных настройках производителя;
5. проверить системную громкость будильника и выполнить «Тест звука».

Приложение не запрашивает запрещённое прямое разрешение на игнорирование оптимизации батареи и не меняет системную громкость самостоятельно.

## 9. Приёмочные сценарии

Проверьте на Android 8, 10, 12, 13, 14 и 15:

- подключение правильным и просроченным кодом;
- push при закрытом приложении и погашенном экране;
- обычную, клиентскую, диспетчерскую и параллельную заявки;
- отмену заявки;
- выключение каждого сценария в настройках;
- громкость 0%, 50%, 100%;
- отключённую вибрацию;
- светлую и тёмную темы;
- запрет уведомлений;
- режим энергосбережения;
- отключение устройства и повторную привязку.
