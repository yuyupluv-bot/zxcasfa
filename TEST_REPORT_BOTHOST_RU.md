# Проверки сборки BotHost

Среда: Python 3.11, зависимости из requirements.txt, локальная PostgreSQL 15.

## Успешно

- 6 тестов нового запуска (`tests/test_bothost_deploy.py`): настройки, ограничения SQL, отсутствие секретов в ошибках конфигурации, перезапуск завершившегося процесса, точка входа.
- 39 существующих регрессионных тестов из `test_v181_fixes_isolated.py`, `test_requirements_v179_resilience.py`, `test_stabilization_v156.py`, `test_requirements_v152_driver_app_controls.py`.
- 23 интеграционные проверки на реальной локальной PostgreSQL (`tests/integration_bothost.py`): health/login/CSRF/админка/APK, одноразовая привязка телефона, device secret, аутентифицированное обновление FCM-токена, выбор адресата push, отключение недействительного токена и отвязка телефона. Вызов FCM подменён, настоящие уведомления не отправлялись.
- 7 runtime-проверок: настоящий Gunicorn и admin watchdog, HTTP-маршруты, доступность веб-панели после принудительного завершения имитированного процесса бота, перезапуск этого процесса, остановка без оставшегося слушающего веб-порта.
- Миграция пустой PostgreSQL до head 0053: успешно после исправления DuplicateColumn в 0049.
- Миграция схемы 0048 без device_secret_hash до head: успешно.
- `pip check`: конфликтов зависимостей не обнаружено.
- Проверка синтаксиса модулей: успешно.
- Исходный Firebase service-account: SDK смог загрузить ключ локально, без отправки FCM. Это не доказывает, что ключ не отозван или имеет необходимые права на сервере Firebase.
- Firebase project_id в исходном service-account совпадает с исходным google-services.json.
- В имеющемся APK найден серверный адрес https://panel.bezrateadminps.ru.

## Не проверено и не выполнено

- Деплой и права постоянного хранилища в вашем аккаунте BotHost.
- Сборка Docker-образа на инфраструктуре BotHost: локальный Docker не использовался.
- Доступность вашей рабочей PostgreSQL, данные и корректность обновления именно вашей базы. Нужна резервная копия.
- Живой Long Poll VK и реальные бизнес-сценарии с вашим сообществом.
- Реальная отправка FCM и звук на телефоне.
- Перенос DNS, сертификат домена и доступность Beget.
- Пересборка Android APK, его подпись и обновление установленного приложения.
- Полный аудит всех бизнес-функций: проверены перечисленные сценарии, не весь проект целиком.

Приватный ключ Firebase не включается в готовый архив. Его нужно отдельно задать в BotHost через FIREBASE_SERVICE_ACCOUNT_B64. Временные тестовые пароли/БД не являются рабочими настройками и в конфигурацию сборки не записаны.
