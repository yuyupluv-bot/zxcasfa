# Назначенные победители розыгрыша

В меню админки откройте «Сделать победителями» и укажите числовые VK ID или ссылки вида `https://vk.com/id123`, по одному на строку. Пользователи должны быть зарегистрированы в базе. Порядок строк определяет места и соответствующие им призы.

Список сохраняется до ручного изменения и применяется ко всем последующим розыгрышам. Очистите поле и сохраните его, чтобы вернуть полностью случайный выбор. Если список короче количества мест, остальные выбираются случайно без повторов. Если назначенных участников больше, чем мест, или кто-то из них заблокирован либо не подходит под текущие условия, розыгрыш не проводится: скорректируйте список или условия.

Назначение победителей обозначается в результатах, в том числе в тексте для публикации. Изменения списка и проведённые розыгрыши записываются в журнал действий администраторов. Данные сохраняются в существующей таблице настроек, миграция не требуется.
