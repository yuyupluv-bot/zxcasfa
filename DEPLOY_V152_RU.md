# БЕЗТАКСЫ v152 — обновление, Firebase и публичная загрузка APK

## Что изменено

- контейнер бота получает `/app/secrets/firebase-service-account.json`;
- push отправляется только активным устройствам, привязанным к конкретному `driver_id`;
- добавлен push об отмене выбранной параллельной заявки;
- удалены кнопки «Пропустить привязку» и «Вернуться к подключению»;
- тест звука показывается только до подключения;
- после подключения показывается одна центральная кнопка включения/выключения уведомлений;
- добавлена публичная ссылка для скачивания APK без регистрации в админ-панели.

## 1. Обновление проекта в GitHub и Portainer

1. Замените файлы репозитория файлами из этого архива и выполните Commit/Push.
2. В Portainer откройте `Stacks` → `vk-taxi`.
3. Нажмите `Pull and redeploy` или `Update the stack`.
4. Убедитесь, что сервисы `migrate`, `bot` и `admin` успешно запустились.

В `docker-compose.yml` уже добавлено для бота:

```yaml
volumes:
  - bot_logs:/app/logs
  - ./secrets:/app/secrets:ro
```

## 2. Firebase

Клиентский файл Firebase должен находиться перед сборкой APK здесь:

```text
android-driver-app/app/google-services.json
```

Серверный файл должен находиться здесь:

```text
secrets/firebase-service-account.json
```

Оба файла должны быть скачаны из одного Firebase-проекта. Серверный файл нельзя публиковать в открытом репозитории.

После развёртывания откройте логи контейнера `vk-taxi-bot`. В них не должно быть `Firebase initialization failed` или `Push failed`.

## 3. Сборка APK

Перед сборкой откройте:

```text
android-driver-app/gradle.properties
```

и укажите публичный HTTPS-адрес сервера:

```properties
DRIVER_APP_SERVER_URL=https://ваш-домен.ru
```

В Android Studio соберите подписанный `release` APK прежним файлом ключа `.jks`. Готовый файл обычно находится здесь:

```text
android-driver-app/app/build/outputs/apk/release/app-release.apk
```

Переименуйте его строго в:

```text
BEZTAKSY.apk
```

## 4. Публикация APK на своём сайте

Положите подписанный файл сюда:

```text
downloads/BEZTAKSY.apk
```

Загрузите его в репозиторий вместе с обновлением и повторно разверните Stack. APK не содержит серверного Firebase-ключа и может быть опубликован.

После запуска админ-сервиса APK будет доступен публично без входа в админ-панель:

```text
https://ваш-домен.ru/driver-app/download.apk
```

Эту ссылку можно отправлять водителям или разместить в VK-боте.

## 5. Подключение водителя

Водителю не нужна учётная запись админ-панели:

1. водитель устанавливает APK;
2. в VK-боте открывает `Мои сведения` → `Подключить приложение`;
3. получает одноразовый шестизначный код;
4. вводит код в приложении в течение 10 минут;
5. после подключения может включать и выключать уведомления центральной кнопкой.

Кнопка выключения действует только на этом телефоне. Привязка водителя сохраняется.

## 6. Адресность уведомлений

Приложение не получает все заявки системы. Сервер выбирает устройства по `driver_id`. Push получают только телефоны, которые кодом привязаны к водителю, которому бот в этот момент отправил конкретное предложение или отмену.

Сценарии: обычная заявка, заявка со своей ценой, заявка диспетчера, выбранная параллельная заявка и отмена назначенной/предложенной заявки.

## 7. Firebase только через Portainer, без SSH

Новая версия поддерживает переменную `FIREBASE_SERVICE_ACCOUNT_B64`. Она имеет приоритет над файлом в `/app/secrets`.

На Windows откройте PowerShell и выполните, указав путь к серверному Firebase JSON:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\путь\firebase-service-account.json")) | Set-Clipboard
```

В Portainer откройте Stack, добавьте переменную окружения:

```text
FIREBASE_SERVICE_ACCOUNT_B64
```

и вставьте значение из буфера обмена. Затем выполните `Update the stack`/`Pull and redeploy`.

Проверка в контейнере бота:

```sh
python -c "import os; print(bool(os.getenv('FIREBASE_SERVICE_ACCOUNT_B64')))"
```

Должно быть `True`. Наличие файла `/app/secrets/firebase-service-account.json` при этом не требуется.

## 8. Альтернативное расположение APK

Сервер также автоматически находит APK, загруженный через GitHub по пути:

```text
android-driver-app/app/downloads/BEZTAKSY.apk
```

После `Pull and redeploy` он доступен по той же публичной ссылке:

```text
https://ваш-домен.ru/driver-app/download.apk
```

Отдельный bind mount для этого варианта не требуется. В Stack также добавлен одноразовый сервис `push-sounds-init`, который автоматически исправляет права Docker-тома пользовательских звуков.

## 9. Исправление уведомления диспетчера после выбора ETA

После выбора времени диспетчер получает только карточку назначенного водителя:

- имя водителя;
- модель и цвет автомобиля;
- номер автомобиля;
- примерное время прибытия.

Водительское сообщение «Время сохранено…» теперь принудительно отправляется только VK-пользователю, который записан в заявке как назначенный водитель. ETA от устаревшего состояния другой роли игнорируется.
