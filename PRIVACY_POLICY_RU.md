# Политика конфиденциальности приложения «БЕЗТАКСЫ»

Дата вступления в силу: 29 сентября 2026 года.

Оператор: самозанятая Перунова Анастасия Анатольевна.

Контакт по вопросам персональных данных: ilia.gat@yandex.ru.

Публичная версия политики: https://panel.bezrateadminps.ru/privacy

## Какие данные обрабатываются

Приложение обрабатывает только данные, необходимые для уведомлений водителя:

- имя водителя, полученное после ввода одноразового кода;
- Firebase push-токен устройства;
- внутренний идентификатор установки и случайный секрет установки;
- технические сведения push-события: тип заявки, номер, маршрут и параметры сигнала.

Приложение не запрашивает геолокацию, контакты, SMS, журнал звонков, камеру, микрофон и доступ к файлам пользователя.

## Цель обработки

Данные используются исключительно для привязки устройства к водителю и доставки уведомлений о заявках, параллельных заявках и отменах.

## Передача и инфраструктура

Push-уведомления доставляются через Firebase Cloud Messaging (Google). Данные также обрабатываются сервером сервиса «БЕЗТАКСЫ» на домене panel.bezrateadminps.ru. Данные не продаются и не используются для рекламы или профилирования.

## Хранение и удаление

Push-токен хранится, пока устройство подключено. Водитель может открыть **Настройки → Отключить устройство**: запись установки и push-токен удаляются с сервера. Для дополнительных запросов на удаление можно написать на ilia.gat@yandex.ru.

## Защита

Обмен с сервером выполняется только по HTTPS. Одноразовый код действует ограниченное время, а постоянный секрет установки хранится на сервере только в виде SHA-256.

## Изменения политики

Новая редакция публикуется по тому же адресу с обновлённой датой вступления в силу.
