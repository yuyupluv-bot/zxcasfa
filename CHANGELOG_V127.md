# V127 — восстановлена доставка заявки водителю

- Публичный номер больше не интерпретируется как внутренний ID при доставке карточки.
- Карточка «Поехать / Отказаться» не удаляется из очереди исходящих сообщений.
- Для современных карточек внутренний ID берётся из payload кнопок.
- Старые карточки без payload продолжают поддерживаться.
